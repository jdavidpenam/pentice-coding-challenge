1Transactions App — Calm wallet (chosen direction)
WHAT THIS IS

Every frame is the same working React-style prototype, preset to a state. Click around — transfers, payments, Check status, user switching, the dev panel all work. Copy is real, not lorem.

SHARED RULES (BOTH)

Reserved always uses a hatched pattern + the word “Reserved”, never colour alone. Status badges carry a glyph and a word. Every input has a visible label; errors sit under the field with “!” and aria-describedby. Buttons disable while a request is in flight. Tabular figures everywhere.

IMPLEMENTATION

Plain CSS: custom properties for tokens, flex/grid, one breakpoint at 700px and one at 1100px. No animation beyond what CSS transitions give you. Status-check results are stored on the payment record, so they survive the row re-rendering.
